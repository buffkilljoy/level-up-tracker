# LEVEL UP — Ultimate Life Tracker

A mobile-friendly, installable 30-day habit tracker. Progress is saved in the browser on the device using localStorage.

## Put it on your iPhone home screen

This app needs to be hosted on an HTTPS website for iPhone home-screen installation and offline support.

### Easiest free route: GitHub Pages
1. On a computer, sign in to GitHub and create a new **public** repository named `level-up-tracker`.
2. Extract this ZIP.
3. Upload all files inside the `level_up_tracker` folder to the repository's root (not the folder itself).
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish the site. It will show a URL similar to `https://YOUR-USERNAME.github.io/level-up-tracker/`.
7. Open that URL in Safari on your iPhone.
8. Tap **Share → Add to Home Screen**. Enable **Open as Web App** if that option appears, then tap **Add**.

## Features
- 30-day calendar and per-day habit checklists
- 4-day Push / Pull / Legs / Shoulders & Arms rotation with recovery days
- Daily nutrition, hydration, sleep and weight logs
- Weekly English practice reminder
- Study, posture, hygiene and financial-work habits
- Weekly completion statistics
- JSON export/import backup
- Offline caching after the first successful visit

## Important data note
Your data is stored locally in the browser on that device. It is not automatically synced between devices. Use **Progress overview → Backup & restore → Export backup** regularly. Import the JSON file to restore it.
